# CVs - Equipo

Repositorio que contiene los **Currículums Vitae (CV)** de los integrantes del equipo, desarrollados como páginas web multipágina.

## Descripción

Este proyecto reúne los CV de nuestros compañeros en un solo repositorio. Cada integrante cuenta con su propia página web, donde presenta información personal y profesional como:

* Perfil personal
* Formación académica
* Experiencia
* Proyectos
* Información de contacto
